## [1.5.0] - 2026-09-18

### Added - Part 2 Submission (Advanced CSS Styling)
- **External Stylesheet:** Fully implemented `css/style.css` across all 5 HTML pages.
- **CSS Variables:** Added `:root` variables for primary colors (#40E0D0), secondary colors (#1A252F), and standard spacing.
- **Fluid Typography:** Implemented `clamp()` for responsive font scaling, eliminating the need for excessive media queries on text.
- **Glassmorphism Header:** Applied `backdrop-filter: blur(10px)` and semi-transparent backgrounds to the sticky navigation bar.
- **CSS Grid & Flexbox:** Replaced basic layouts with responsive `auto-fit` grids for stats, team members, values, and location cards.
- **Pseudo-classes & Interactivity:** Added `:hover`, `:focus`, and `:active` states for all buttons, links, and form inputs. Implemented glowing borders and 3D lift effects (`transform: translateY`).
- **Responsive Design:** Added comprehensive media queries for Tablet (max-width: 768px) and Mobile (max-width: 480px), including layout restructuring and image scaling (`max-width: 100%`).
- **Decoration:** Added gradient backgrounds, box shadows, and border-radius for a cohesive, modern aesthetic.

### Removed
- Removed inline styles from HTML files (moved to external stylesheet).
